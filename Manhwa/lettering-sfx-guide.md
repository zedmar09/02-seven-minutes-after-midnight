# Manhwa Lettering and SFX Guide

## Dialogue

Use clean mobile-readable speech balloons with enough padding. Keep tails unambiguous. Do not shrink text merely to preserve a composition; reflow/recompose art instead.

Preserve locked wording, speaker/source, order, punctuation, capitalization, and text type.

## Balloon / Tail Evidence Safety — Absolute

Dialogue, narration, physical text, and SFX may never hide continuity-critical physical evidence.

Do not cover or sever:
- hand→tray/counter/window contact
- wrist catch/release
- tongs→bread→saucer handling
- saucer/paper threshold crossing
- apron-pocket placement
- notebook/page/pencil actions
- token identity/location
- flashlight fall
- clock hands/time
- service-window frame/opening
- scratched warnings on glass
- object-aging proof

If lettering conflicts with action proof, move/recompose the lettering or camera—not the physical event.

## Narration / Time Captions

Narration wording is locked, but treatment may respond to function while staying one coherent publication typography family.

Useful treatments:
- archival/investigation observation — restrained editorial caption
- time/location transition — compact clear caption
- quiet romantic realization — minimal unobtrusive treatment
- ominous evidence reveal — sparse higher-contrast treatment
- suspense/listening — often let art/silence dominate

Never reuse one identical top-left narration box for every line.

Narration must not imitate:
- speech balloons
- physical handwriting
- station signage
- clock UI
- production metadata

Never invent narration to fill vertical space.

## Internal Thought

Internal thought uses a distinct readable treatment and must never be visually acted as spoken dialogue.

## Physical Handwriting — Absolute

Writing exists on the real paper carrier.

Chapter 1 exact writing includes:

Daniel's acid-free sleeve:

`DANIEL SORIANO`

`SAN AURELIO MUNICIPAL MUSEUM`

`2026`

`I am real.`

Daniel's later torn warning page:

`DO NOT TELL ANYONE ABOUT ME.`

`KEEP THIS HIDDEN.`

`COME BACK TOMORROW.`

Returned page adds Tomas's line:

`I will bring better bread.`

Physical handwriting must remain on the SAME page/sleeve across close-ups and time transformation. Do not recreate a clean new copy after crossing.

## Scratched Glass Text — Absolute

The 2026 painted cafe glass carries:

`TOMAS`

and, revealed later below it:

`FIRE STARTS IN THE SERVICE CORRIDOR.`

These are scratches in physical painted glass. Do not render them as captions, neon text, UI, holograms, or floating horror typography.

## Clock Text

Clock time remains physically attached to the canonical clock face. Exact minute progression is story-critical and must be mobile-readable whenever the clock is used as evidence.

## Station Announcements / Offscreen Audio

1986 station announcements and Lilia's kitchen line are real environmental audio.

- establish real story-world source direction
- lettering treatment must read as offscreen/environmental audio, not a visible human balloon from Daniel's side
- Daniel/Tomas reactions orient toward the real source when relevant
- camera changes cannot move the source to a different wall/era

## Same-Object Close-Up / Insert Rule — Absolute

A close-up, inset, magnified detail, clock insert, paper detail, scratch detail, or threshold detail does not create a second physical object.

Same-moment views show compatible state. Later-action views advance the state exactly once.

Examples:
- token close-up does not leave a second token under the counter
- clock insert is the same clock in the environment
- aged bread detail is the same bread that crossed
- returned-note close-up is the same torn page on Daniel's side
- scratch close-up is the same painted glass door

## SFX Physical-Logic Gate — Absolute

Every scripted SFX must pass:

`PHYSICAL SOURCE → PHYSICAL ACTION → EXACT SOUND → TIMING → PLACEMENT → STATE CHANGE → NEXT CONSEQUENCE`

If any field is unexplained, audit the action rather than using SFX to hide missing mechanics.

Potential Chapter 1 physical sounds include, only when the locked strip actually uses them:
- old gate scrape/complaint
- clock click/tick
- token drop
- tray/contact
- service-window movement
- flashlight floor impact
- pencil-lead snap
- connection flicker/light shutoff

Do not invent generic footsteps, rain SFX, steam SFX, heartbeat typography, portal whooshes, or horror impacts merely to make art busier.

## SFX Placement

Place at actual source and do not cover faces, hands, clock, paper, glass scratches, object transformation, or threshold action.

## Persistent-State Continuity

When sound changes physical state, that result persists:
- token drop establishes a new token location
- window opening establishes open-window state
- flashlight impact establishes floor location
- pencil snap establishes broken-pencil state
- lights shutting off establish changed 1986 lighting state

A camera cut does not reset the result.

## Seam Safety

All reader-facing words sit fully inside one technical strip. Never split a speech balloon, handwritten line, scratch warning, clock face, or critical SFX across a technical seam/divider.

## NO Reader-Visible Production Text — Automatic Reject

Never print:
- `V01`, `V-01`, `V###`
- `P001`, page labels
- `strip-001`, `Strip 001`
- `BEAT`, `PANEL`, `SCENE`, `SHOT`
- `SFX:` as a production label
- era-state names
- temp-state names
- character/reference filenames
- crop marks, QA notes, prompt notes, headers/footers

Any visible production metadata is automatic rejection.

## Re-Audit Rule

After correcting dialogue, lettering, SFX, physical writing, scratch text, clock text, source ownership, or object state, re-audit the corrected beat and neighboring beats/seams for new timing/ownership/continuity defects.
