# Manhwa Production Readiness Gate

The vertical Manhwa pipeline is the permanent production format.

A chapter is **PRODUCTION COMPLETE** only when every mandatory gate passes in the current post-correction state. Earlier PASS labels never substitute for a fresh final audit.

Always-binding hardening authorities:
- `seventh-hardening-visual-logic-addendum.md`
- `eighth-hardening-presentation-integrity-addendum.md`
- `ninth-hardening-character-topology-identity-addendum.md`
- `tenth-hardening-pose-performance-continuity-addendum.md`

## Character Topology / Identity Failure — BLOCKING

Reject extra/missing/duplicated limbs, detached hands/feet, impossible joints, close-up limbs that cannot connect to adjacent body, mirrored/migrated permanent marks, face/hair/age/build drift, wardrobe reset, or glossy/cinematic recasting.

## Pose / Performance Failure — BLOCKING

Reject silent changes to standing/leaning/seated/walking state, weight-bearing legs, shoulder/hip/torso facing, head-vs-torso relationship, gesture, relative scale, emotional intensity, sleeve/glove/glasses/apron state, or hair construction.

A camera cut is not a performance reset.

## Dual-Era Geometry Failure — BLOCKING

Reject if:
- 1986 Cafe Siete and 2026 Cafe Siete have incompatible structural footprints
- service window changes location/size/mechanism
- counter changes shape/orientation without documented renovation
- clock/menu wall migrates
- a reverse shot mirrors fixed architecture

Age/damage/furniture/signage may differ; underlying architecture may not casually redesign.

## Era / Clock Failure — BLOCKING

Reject any wrong/repeated/skipped minute or impossible era state.

Chapter 1 sequence is absolute:

`2026 stopped 12:07 → activation 12:00 → 12:01 → 12:02 → 12:03 → 12:04 → 12:05 → 12:06 → 12:07 close → 2026 stopped 12:07`

## Time-Crossing Object Failure — BLOCKING

Reject:
- aged replacement object instead of same object
- duplicate before/after copies read as two physical objects
- wrong direction of aging
- transformation before crossing
- lost handwriting/content
- page/saucer/bread identity changes
- object silently reappears at origin after crossing

## Physical Text Failure — BLOCKING

Reject wrong, floating, duplicated, unreadable, or incorrectly timed:
- `TOMAS`
- `FIRE STARTS IN THE SERVICE CORRIDOR.`
- Daniel identity/year/`I am real.` sleeve
- Daniel three-line warning
- Tomas's `I will bring better bread.` addition
- clock time when shown as story evidence

## Required-Asset Rule — BLOCKING

Missing/stale/wrong-path/unapproved required WebP → STOP. A prompt Markdown file is not a visual authority.

## Repository Image Format Rule

Reference generation may produce local PNG first. After visual approval, manually convert to WebP and commit/store the WebP authority.

## Completion Language

Use `PRODUCTION COMPLETE` only after all mandatory rendered/seam/stitch/final-audit gates pass.

Accurate intermediate statuses include:
- `BLOCKED — REQUIRED CANONICAL VISUAL AUTHORITY MISSING`
- `HARDENED PREPRODUCTION GATE PASS — READY FOR SEQUENTIAL STRIP GENERATION`
- `VISUAL QA FAILED — REPAIR / REGENERATE BEFORE NEXT STRIP`
- `VISUAL QA IN PROGRESS — NOT PRODUCTION COMPLETE`

Do not reintroduce the retired page-grid pipeline.
