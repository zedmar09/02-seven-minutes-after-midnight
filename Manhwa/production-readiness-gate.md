# Manhwa Production Readiness Gate

A chapter is **PRODUCTION COMPLETE** only when every mandatory gate passes in the current post-correction state. Earlier PASS labels never substitute for a fresh final audit.

## Mandatory Gates

1. continuous-scroll beat plan locked
2. strip manifest locked
3. story/event/timeline/causality coherent
4. exact dialogue/narration/note/sign/clock text and ownership locked
5. approved required character WebPs exist
6. approved required environment WebPs exist
7. approved required recurring-object WebPs exist
8. previous approved strip used only for temporary state/seam continuity
9. dual-era architecture remains one physically compatible structure
10. exact 12:00→12:07 state progression is coherent
11. object crossings preserve one-object provenance
12. forward/backward aging state follows story rules
13. service-window geometry/mechanics remain stable
14. every strip has deterministic START → CHANGES → END
15. every critical action shows cause → visible mechanism → result
16. hands/body support physically possible
17. whole-body topology contains no extra/missing/duplicated limbs
18. close-up limb ownership matches adjacent body state
19. face/age/build/hair identity remains canonical
20. wardrobe/accessory/material state remains stable within continuous scenes
21. pose/facing/gesture/emotional state persists across adjacent views until visibly changed
22. same-object wide/detail views do not create duplicates
23. recurring objects retain stable scale/construction
24. camera axis/eyelines remain coherent around counter/service-window
25. critical text remains on physical carrier and mobile-readable
26. clock never shows contradictory decorative time
27. 1986-only and 2026-only state do not contaminate each other
28. practical lighting/rain/steam sources remain physically coherent
29. lettering/SFX never cover decisive evidence/contact
30. no reader-visible technical metadata
31. strict flat 2D human-drawn Korean Manhwa style passes actual visual inspection
32. every strip generated/approved sequentially
33. stitched chapter has no seam duplicates, time jumps, pose resets, age resets, object teleports, architecture jumps, or era contamination
34. final ending matches locked script exactly
35. fresh clean-room final audit finds zero unresolved mandatory findings

## Chapter 1 Mandatory Evidence

The final Chapter 1 must visibly preserve the locked evidence chain in `characters.md`, including the brass token, `TOMAS` scratch, 12:00 activation, 1986/2026 reveal, service-window opening, pastry aging test, `I AM REAL.` paper exchange, Arturo mention, 12:06 shutdown pressure, warning-note exchange, 12:07 closure, returned forty-year-old page with `I WILL BRING BETTER BREAD.`, and final `FIRE STARTS IN THE SERVICE CORRIDOR.` reveal.

## Missing Asset Rule — BLOCKING

Required WebP missing/stale/wrong-path/unapproved → STOP. Prompt Markdown is not a substitute for the approved image authority.

## Flat 2D Failure — BLOCKING

Reject photoreal, semi-realistic, 3D/CGI, glossy, cinematic, painterly, airbrushed, bloom-heavy, depth-of-field, plastic-skin/hair, or over-rendered output even if the prompt says "2D".

## Time / Clock Failure — BLOCKING

Reject wrong, skipped, duplicated, reversed, or visually contradictory minute state. A time change requires scripted causal progression.

## Object Provenance Failure — BLOCKING

Reject duplicated notes, pastries, saucers, token, tray, notebook page, or other crossing/evidence objects; reject aging that silently resets or occurs before crossing.

## Dual-Era Geometry Failure — BLOCKING

Reject a service window, counter, wall, clock location, station route, or structural opening that becomes a different building between 1986 and 2026 without story cause.

## Completion Language

Allowed intermediate statuses include:
- `PREPRODUCTION AUDIT IN PROGRESS — NOT READY TO GENERATE`
- `BLOCKED — REQUIRED CANONICAL VISUAL AUTHORITY MISSING`
- `HARDENED PREPRODUCTION GATE PASS — READY TO GENERATE STRIP 001`
- `VISUAL QA FAILED — REPAIR / REGENERATE`
- `VISUAL QA IN PROGRESS — NOT PRODUCTION COMPLETE`

Use `PRODUCTION COMPLETE` only after every rendered, stitch, and fresh-final-audit gate passes.
