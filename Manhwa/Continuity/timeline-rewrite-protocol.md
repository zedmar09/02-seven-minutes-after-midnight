# Timeline Rewrite / Settlement Protocol — Creator Only

This file defines how changes made in 1986 become reality in Daniel's 2026.

## 1. Settlement Timing — Absolute

During an open midnight connection, Daniel's surrounding 2026 world remains on the **pre-change historical state** except for local threshold effects such as crossing-object aging or the coffee-ring imprint.

A historical alteration settles into 2026 only when the current connection closes.

If the current duration is seven minutes, settlement begins at `12:07:00`.
If a later connection closes at `12:06:43`, settlement begins then.

This prevents the external world from rewriting in the middle of one conversation.

## 2. Settlement Wave

After closure, causal changes propagate through 2026 from the smallest affected historical branch outward.

Typical visible results:
- wording in archive records changes
- a photograph gains/loses a person or detail
- accession numbers or box contents shift
- a survivor statement changes
- physical damage or repair history changes
- a hidden object now exists where it previously did not

A rewrite is not a flashy visual wave. It should normally appear as quiet physical contradiction discovered after closure.

## 3. Causal Scope

Only facts downstream of the changed 1986 action rewrite.

Do not use timeline changes as permission to randomly redesign unrelated architecture, characters, weather, objects, or institutions.

Every changed 2026 fact must have a traceable causal path back to the specific 1986 alteration.

## 4. Daniel's Memory

Because Daniel is a direct participant inside the Cafe Siete boundary at settlement, he initially retains **dual memory**:
- memory of the pre-change 2026 state
- awareness of the newly settled 2026 state

He does not instantly forget the old version.

Repeated major rewrites create pressure:
- headaches
- word-retrieval slips
- contradictory sensory memory
- uncertainty about which version was original

This becomes the foundation for later memory-risk arcs.

## 5. Tomas's Memory

Tomas remembers his lived 1986 sequence normally.

He does not gain automatic knowledge of the future state created by his action unless Daniel reports it in a later connection.

## 6. Other People's Memory

Ordinary people in 2026 default to the **new settled history only**.

Maribel, Ernesto, and other allies do not automatically remember the overwritten version merely because Daniel does.

An ally may later gain partial old-state memory only through an explicitly established anchor exposure or stronger time-slip event.

## 7. Temporal Anchors

### Class A — Cross-era physical artifacts
Objects that have physically crossed the service window can resist ordinary rewrite because their provenance spans both histories.

Examples:
- the returned warning page
- future letters that make a full crossing
- photographs or evidence intentionally carried through the aperture

### Class B — Boundary-exposed handwritten field record
Daniel's physical notebook, while present inside Cafe Siete during settlement, can preserve his own pre-change handwritten observations even when external records rewrite.

This is not unlimited protection: pages removed from the boundary or later rewritten by stronger fixed-point changes may still be affected.

### Class C — Ordinary external records
Normal photographs, scans, database entries, cloud files, museum copies, newspapers, and records outside the boundary update to the new history if causally affected.

Digital duplication is therefore not an easy way to defeat the timeline.

## 8. Object History After Backward Transfer

A 2026 object sent to 1986 becomes part of 1986 causal history after closure.

It does not remain frozen in a magical new state.

If hidden for forty years, it ages.
If burned, it is burned.
If photographed, the photograph can enter the record.
If moved, its eventual 2026 location changes accordingly.

Track the actual path in `temporal-object-provenance-ledger.md`.

## 9. Rewrite Magnitude

The connection does not charge a simple fixed price per action. Cost is nonlinear and depends on how much established history must bend.

Useful creator categories:
- observational/no third-party change — usually zero cost
- personal/private change — low risk
- documentary footprint — moderate cost
- witness/schedule/evidence-survival change — high cost
- fixed-point challenge — extreme cost
- forced living-boundary violation — damages the wound even without changing history

The exact Arc 1 costs are authority in `time-slip-state-ledger.md`.

## 10. Fixed-Point Protection

The November 23, 1986 San Aurelio fire is a strong fixed event.

Directly preventing ignition, evacuating the entire station far in advance, or removing the causal conditions that create the abandoned Cafe Siete risks erasing Daniel's access to Tomas.

A survivable solution must eventually alter **who is where / what survives / how a person escapes** without casually deleting the fire itself.

## 11. No Retroactive Convenience

Do not rewrite history solely to repair a continuity mistake.

If production discovers a contradiction, fix the canon documents/prompts. Timeline magic is never a substitute for editing discipline.
