# Object Reference Policy

## Permanent Authority

Approved recurring-object `.webp` files define stable body proportions, construction, markings, materials, scale, wear vocabulary, moving parts, and identity. Prompt Markdown and previous strips are subordinate.

## Same-Object Rule

A close-up, inset, crossing-state detail, or before/after age detail does not create another physical object. The same physical item must preserve provenance and advance state exactly once.

## Scale / Fit

Recurring objects keep stable world-space size relative to hands, counter, notebook, pockets, saucers, shelves, and other approved environment/object references. Perspective may change screen size but not physical scale.

## Aging Across Time

When a canonical recurring object crosses time, preserve its identity while applying story-authorized age transformation. Aging may alter surface condition, stain, corrosion, color/value, brittleness, cracking, dryness, or wear but must not silently redesign shape or markings.

## Derived Details

If a tiny non-plot mechanical detail is omitted from the canonical, derive only the smallest necessary compatible detail. Do not promote a generated redesign into permanent canon.

## Approval Gate

Missing, stale, wrong-path, or unapproved required recurring-object WebP is blocking before a strip that depends on that object.
