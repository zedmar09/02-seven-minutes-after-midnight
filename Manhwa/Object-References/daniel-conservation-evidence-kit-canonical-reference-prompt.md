## Absolute Style

STRICT FLAT 2D HUMAN-DRAWN KOREAN MANHWA/WEBTOON OBJECT REFERENCE.
Clean linework, flat matte colors, restrained hard-edged cel shading, neutral reference lighting, accurate ordinary scale.

No photorealism, CGI/3D, glossy product-ad finish, dramatic reflections, cinematic lighting, branding or decorative fantasy design.

## Canonical Components

### `NOTEBOOK-DANIEL-01`
- compact A5-class field notebook
- matte charcoal/dark-gray cover
- simple bound spine
- no logo, decorative title, elastic band or ornamental hardware unless later explicitly revised
- off-white paper
- stable scale relative to Daniel's hands

### `PENCIL-DANIEL-01`
- one plain natural-wood hexagonal graphite pencil
- no branding
- no colored decorative paint
- no eraser cap
- normal adult writing scale
- show **two allowed states of the SAME design**: intact usable point and later chipped/blunt exposed-graphite point
- the chipped state is not a second pencil

### `LOUPE-DANIEL-01`
- small folding conservation magnifying loupe
- matte dark/black and muted metal construction
- compact enough for one-handed use
- no screen, light ring or electronic UI

### Archival Paper / Sleeves
- clean A5-class acid-free archival sheets suitable for service-window exchange
- clear acid-free polyester photograph/page sleeves
- low-reflection transparent material
- no glossy plastic-ad shine

### Hand Tools
- small archival tweezers
- soft conservation brush
- ordinary compact tool-tray scale

### Conservation Gloves
- thin clean white cotton conservation gloves matching Daniel's established chapter design
- removable equipment, never fused to hands

## Continuity Use

Chapter 1 Strips 001–003 use this reference for notebook, pencil, loupe, sleeves and archive gloves. Later strips reuse the same notebook/pencil/paper/sleeve identity. Strip 029 changes only the pencil point state; it does not redesign the pencil.

Do not treat story-specific fire reports, witness statements, photographs or handwritten warning pages as generic duplicates from this reference. Their content/carrier state remains script-specific.
