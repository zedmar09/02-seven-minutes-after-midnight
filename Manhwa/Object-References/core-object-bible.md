## Material Style

All objects remain strict flat 2D matte manhwa materials. Brass may use restrained hard highlights but never mirror chrome. Ceramic is ordinary matte/glazed with controlled flat highlights, not photoreal. Paper has simple flat aging cues, not hyperreal texture rendering.
