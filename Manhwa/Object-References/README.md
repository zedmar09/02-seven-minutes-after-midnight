## Authority

Approved object WebPs control stable construction, proportions, neutral materials, markings, and reusable state vocabulary. Current strip controls exact current text, damage, age, contents, and temporary state.

A reference prompt Markdown file is not a visual canonical. Missing required approved WebP blocks rendered strip production.
