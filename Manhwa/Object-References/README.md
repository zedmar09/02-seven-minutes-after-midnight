## Two-Clock Object Rule — Absolute

`CLOCK-STATION-01` and `CLOCK-CAFE-01` are separate physical objects.

Station clock:
- large matte dark-iron institutional clock
- ivory enamel face
- hour/minute hands only
- no brass rim
- fixed `12:07` in 2026
- never resets during Cafe meetings

Cafe clock:
- smaller brass-rimmed Cafe Siete wall clock
- includes thin second hand
- resets to `12:00` at connection activation
- controls the active interval

Never merge their design, location, behavior or hand state.

## Fictional-World Rule

Objects belong to fictional Caligo Vale / San Aurelio. Do not reproduce real government forms, railway logos, newspaper identities, civic seals or geographic branding.
