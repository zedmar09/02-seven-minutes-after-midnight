## START STATE

Define exact inherited state:

- wardrobe/accessories
- object locations/count/orientation/age

- clock minute
- 1986/2026 environment state
- lighting/rain/steam/audio state

## ALLOWED CHANGES

List only scripted changes permitted during this strip.

## MANDATORY STORY BEATS

Write top-to-bottom reader beats in exact causal order. Preserve exact dialogue/narration/note/sign/time text.

## PHYSICAL MECHANISMS

For every continuity-critical action define one mechanism with visible contact/source/result.

## TIME-SLIP / OBJECT PROVENANCE

For each crossing object specify:
- same physical object identity
- origin era
- source hand/surface
- threshold crossing
- age/state transformation
- destination hand/surface
- final location

## CAMERA / GEOGRAPHY

- preserve approved environment geometry
- preserve world-space character sides
- preserve service-window/counter/clock relationships
- no fisheye or forced scale distortion
- use same-object detail views when mobile proof needs enlargement

## LETTERING / SFX

List exact text and source. Place physical text on the real carrier. Keep SFX at the action source and never cover decisive proof.

## VISUAL STYLE — ABSOLUTE

Strict flat 2D human-drawn Korean manhwa/webtoon; clean intentional linework; flat colors; restrained hard-edged cel shading; matte materials; stable adult anatomy; natural hands.

Reject photorealism, 3D/CGI, glossy/plastic rendering, airbrush/painterly realism, cinematic grading, bloom, lens flare, depth-of-field blur, excessive reflections, and AI-polished over-rendering.

## END STATE / SEAM OUT

Record exact state inherited by the next strip:
- pose/facing/gesture
- held/placed props
- exact clock minute
- object provenance/age/location
- service-window state
- era activation state
- lighting/weather/audio
- emotional intensity

## VISUAL QA GATE

Reject if any production-readiness requirement fails. Do not continue to the next strip until the actual rendered image passes current QA.
