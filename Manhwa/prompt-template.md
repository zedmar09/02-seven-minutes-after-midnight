# Technical Strip Prompt Template

Use this structure for every active Manhwa production strip.

```text
Create exactly ONE tall full-color flat-2D manhwa TECHNICAL STRIP belonging to the same continuous chapter scroll.

CONTINUOUS-CHAPTER LOCK
This is not a page, episode, or reader-visible production part.

PRODUCTION AUTHORITY
Use current chapter continuous-scroll plan + strip manifest + this strip's exact locked reader-facing script. Binding style/SFX/seam/layout/workflow/readiness/hardening rules always apply. Current strip may be stricter, never looser.

INTERNAL READ BEATS — PRODUCTION ONLY
V###–V### planning IDs only. NEVER render V/P/strip/beat/scene/panel/shot/QA/era-state/temp-state metadata anywhere.

ATTACH — REQUIRED
List EVERY exact required visual reference:
- character canonical WebP path(s)
- environment canonical WebP path(s)
- object canonical WebP path(s)
- previous approved strip for 002 onward
- current prompt
Do not infer attachments from another file.

REFERENCE AVAILABILITY — BLOCKING
Missing/stale/wrong-path/unapproved required canonical → STOP. Never substitute a Markdown prompt, legacy page render, rejected image, or improvised design.

ATTACHED-REFERENCE OBEDIENCE — ABSOLUTE
Approved WebPs are binding permanent identity/geometry/object authority, not inspiration. Recompose the shot; never redesign canon.

PREVIOUS-STRIP LIMIT — ABSOLUTE
Previous approved strip controls temporary story state only. It never overrides permanent canon.

REFERENCE PRIORITY
Current user instruction > current story/chapter/strip > approved character > approved environment > approved object > binding global rules > previous approved strip temporary state > minimal canon-compatible derived micro-detail.

ERA / CONNECTION STATE — ABSOLUTE
State exact current story-world condition:
- 2026 abandoned/closed
- connection opening/shared threshold
- 1986 active side visible during connection
- destabilizing connection
- 2026 post-close
Production wording only; NEVER render labels.

CLOCK STATE — ABSOLUTE
State exact clock minute and whether it is stopped/moving. Current strip may change minute only at the exact scripted transition.

LEGAL TIME / LOCATION CUT
State what a legal cut may change and what evidence/identity persists. It may establish new temporary pose/ordinary clutter but never resets permanent canon, object provenance, scratch text, architecture, or lost-minute history.

START STATE — ABSOLUTE
List exact:
- character pose/support/facing/feet/distance
- head vs torso orientation
- hands/held items/anatomical side
- emotional intensity and active gesture
- clothing-layer/sleeve/glove/glasses/hair-tie state
- object count/location/orientation/scale/age/damage/writing
- service-window/door/glass/counter state
- era/clock/connection state
- lighting/audio source state
- previous seam anchors

ALLOWED CHANGES — ABSOLUTE
List only physical/performance/story changes allowed in this strip. Anything not listed stays unchanged.

DETERMINISTIC SINGLE-MECHANISM — ABSOLUTE
Choose ONE physically authoritative solution for each continuity-critical action. Do not give alternatives that produce different hands/poses/object locations.

END STATE — ABSOLUTE
List exact physical/performance/era/clock/object/text state carried to next strip.

WHOLE-BODY ANATOMICAL TOPOLOGY — ABSOLUTE
Every character is one physically coherent human body. Reject extra/missing/duplicated limbs/body parts, detached hands/feet, impossible joints, or close-up limb incompatible with adjacent wide-shot body.

LIMB OWNERSHIP / ANATOMICAL SIDE — ABSOLUTE
A close-up hand/wrist/arm/foot belongs to SAME character and SAME physical side established by adjacent views. Reverse shot may flip screen side; ownership may not.

PERMANENT CHARACTER LANDMARKS — ABSOLUTE
Repeat all relevant character-specific locks.
Daniel: close-cropped curls + early temple silver + stable nose-bridge scar + adult slim build + rectangular glasses when worn.
Tomas: long dark wavy hair + low nape tie + jade cord + adult lean baker build + stable shirt/apron construction.
Other recurring characters use exact attached canonical locks.

FACE / AGE / BUILD / HAIR IDENTITY — ABSOLUTE
Close-ups, expressions, warm/cold lighting, rain, darkness, or time-era contrast may not recast the character.

POSE-STATE CONSERVATION — ABSOLUTE
Camera cut is not pose reset. Track standing/leaning/crouching/walking/support, weight-bearing legs, shoulders/hips/torso facing, head orientation, arm gesture, hand height, spine lean, feet, center of mass.

RELATIVE HEIGHT / BUILD — ABSOLUTE
Perspective changes screen size only. World-space body scale remains canonical.

EXPRESSION / EMOTION CONTINUITY — ABSOLUTE
Carry emotional intensity until real story cause changes it. Use grounded adult performance; no random panic/seduction/villain/chibi/glamour acting.

GESTURE CONTINUITY — ABSOLUTE
Current hand/arm gesture persists until visibly released/changed or legal cut establishes another state.

CLOTHING-LAYER / SLEEVE / GLOVE / ACCESSORY STATE — ABSOLUTE
Preserve exact current wear state within continuous scene. A reverse shot may not roll sleeves, remove gloves, move glasses, retie hair, or change apron/jacket state without action.

HAIR / GARMENT MOTION — ABSOLUTE
Natural motion may move flexible shapes but not redesign them.

WARDROBE / LOCAL-COLOR / MATERIAL — ABSOLUTE
Preserve construction, signature color, and matte material family.

SPEAKING / LISTENING / AUDIO OWNERSHIP — ABSOLUTE
Visible acting agrees with line source. Listener does not mouth another speaker's line. Offscreen Lilia/station audio remains offscreen unless explicitly shown. Physical handwriting/scratches are not spoken dialogue.

MICRO-CONTINUITY — ABSOLUTE
Visible story state persists slice X→X+1 unless visible/legal change occurs.
Track when relevant: token, tray, tongs, bread, saucer, flashlight, notebook, pencil, acid-free sleeve, torn page, apron pocket, service window, cafe glass scratches, clock, era/light state.

TEMPORARY ANATOMICAL-SIDE IDENTITY — WHEN APPLICABLE
Use internal labels such as TOKEN HAND / FLASHLIGHT HAND / NOTEBOOK HAND / PENCIL HAND / TRAY HAND / TONGS HAND / WRIST-CATCH HAND / WINDOW HAND only where needed. NEVER render labels.

ORIENTATION / HINGE / TRACK CONSERVATION — ABSOLUTE
Preserve service-window mechanism, cafe gate/door geometry, notebook spine/page direction, tray/saucer orientation, clock/counter architecture.

OBJECT SCALE / FIT CONSERVATION — ABSOLUTE
Recurring objects retain stable world-space size; close-up magnification is representational only.

DEPTH / CONTACT — ABSOLUTE
2D overlap is not contact. Show real grips/support and physically readable threshold depth.

FLEXIBLE OBJECT / GRAVITY / NO-CLIPPING — ABSOLUTE
Paper/hair/apron ties/clothing/falling flashlight/crumbs obey support/gravity/collision.

CAMERA AXIS / EYELINE — ABSOLUTE
Continuous conversation preserves story-world sides and gaze targets. Crossing 180° axis requires neutral reorientation.

PERSPECTIVE / LENS — ABSOLUTE
Ordinary manhwa perspective only; no fisheye/ultra-wide/forced-perspective warping.

MOBILE-SCALE EVIDENCE LEGIBILITY — ABSOLUTE
Critical proof must be readable at normal phone size. Use adjacent SAME-OBJECT details, never world-space resizing.

CROP / GUTTER / DIVIDER SAFE MARGIN — ABSOLUTE
Never amputate decisive contact, threshold crossing, clock, scratch, paper, or object transformation.

PHYSICAL TEXT-PLANE — ABSOLUTE
Scratches remain on glass; handwriting on paper; clock text on clock; station signs on physical signage.

LIGHTING SOURCE / SHADOW DIRECTION — ABSOLUTE
Keep physical light logic for 2026 abandoned state, 1986 warm cafe state, 12:06 collapse, and 12:07 return. No cinematic invented light.

REFLECTION / SHADOW FALSE-DUPLICATE BAN — ABSOLUTE
No unscripted reflected/shadow duplicate humans/hands/objects or ghost silhouettes.

GRIP / FINGER ERGONOMICS — ABSOLUTE
Critical grips are mechanically usable: tray, tongs, wrist, pencil, paper, token, notebook, flashlight.

AUDIO SOURCE / REACTION DIRECTION — ABSOLUTE
Station/Lilia/offscreen sounds remain at real story source and reactions orient correctly.

TOP-TO-BOTTOM READER ORDER — ABSOLUTE
Action, dialogue, narration, clock insert, physical text, and SFX read in exact scripted causal order.

REAL-SCENARIO CAUSALITY — ABSOLUTE
START STATE → CAUSE → VISIBLE PHYSICAL ACTION → RESULT → PERSISTENT END STATE.

MANDATORY ACTION-PROOF FRAMING — ABSOLUTE
Show decisive contact or immediately adjacent causal detail. Text/SFX/result cannot replace mechanism.

SAME-OBJECT REPRESENTATION / INSERT — ABSOLUTE
Close-up/inset does not create another copy. Same-moment views agree; state advances once.

TIME-CROSSING OBJECT PROVENANCE — WHEN APPLICABLE
List exact origin era → owner/location → threshold action → transformation → destination owner/location → persistent state.

DUAL-ERA ARCHITECTURE — ABSOLUTE
1986/2026 are same underlying building. State may differ; permanent geometry may not independently redesign.

SERVICE-WINDOW RULE — ABSOLUTE
Use exact canonical opening/size/mechanism. Small objects/hands only under current story rules; never enlarge to fit a body or prettier romance pose.

LETTERING / SFX EVIDENCE SAFETY — ABSOLUTE
Reader text cannot cover proof or reorder causal events.

STRICT FLAT 2D HUMAN-DRAWN STYLE — ABSOLUTE
Clean line art, flat colors, restrained hard-edge cel shading, matte materials, stable anatomy. NO photoreal/3D/glossy/cinematic/painterly/airbrushed/over-rendered output.

SEAM IN
State exact inherited anchors.

VERTICAL COMPOSITION
Continuous manhwa composition, not printed-page grid.

SCRIPT / SOURCE OWNERSHIP LOCK
List exact reader-facing dialogue/narration/SFX/clock/scratch/handwriting text and source.

SFX PHYSICAL CHAIN
SOURCE → ACTION → EXACT SOUND → TIMING → PLACEMENT → STATE CHANGE → NEXT CONSEQUENCE.

NO DEAD BOTTOM
No giant unused tail or invented filler.

SEAM OUT
Define exact next-strip physical + performance + era + clock + object state.

AUTOMATIC REJECT IF
- missing/unapproved reference
- legacy page prompt/render used as authority
- permanent canonical redesign
- era/clock state wrong
- object provenance/aging wrong
- architecture/service-window drift
- contradictory physical alternatives
- teleport/object duplication
- pose/body-facing reset
- emotional/gesture reset
- anatomy/limb ownership failure
- landmark/hair/wardrobe drift
- same-object insert duplicates state
- hinge/track flips
- fake contact/depth
- flexible object floats/clips
- camera axis/eyeline wrong
- lens distortion
- critical proof microscopic/cropped
- lighting/source contradiction
- reader order wrong
- physical text floats/leaves carrier
- reflected/shadow duplicate appears
- impossible grip
- audio source wrong
- lettering hides evidence
- any production metadata visible
- dead canvas/filler
- visible technical seam
- strict flat-2D violation
```

After any correction, re-audit corrected strip and adjacent seams. After the final strip, run a fresh clean-room audit of the stitched chapter.
