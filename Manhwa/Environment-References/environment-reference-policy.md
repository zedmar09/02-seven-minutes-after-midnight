# Environment Reference Policy

## Permanent Authority

Approved environment `.webp` files are permanent production authority for recurring location geometry. Prompt Markdown and previously generated strips are subordinate.

## Canon Controls

Environment references control:
- structural footprint
- walls, doors, windows, openings
- counter/service-window placement and dimensions
- clock/menu-wall relationship
- fixed station/cafe architectural landmarks
- recurring furniture/fixture zones when story-critical
- route plausibility
- camera-axis truth and physically possible reverse views
- world-space scale

## Dual-Era Rule

Cafe Siete and San Aurelio Junction in 1986 and 2026 are the same physical building in different historical states.

Allowed era changes:
- age/wear/damage
- occupancy
- removable furniture/stock appropriate to history
- operational versus abandoned fixtures
- signage condition
- dust/debris/redevelopment intrusion
- practical lighting state

Forbidden without explicit story cause:
- moving structural walls/openings
- changing service-window location
- changing counter footprint to fit a shot
- moving the clock to a different wall
- mirroring architecture
- inventing doors/routes that contradict canon

## Derived Micro-Detail

If a small practical detail is not legible in approved references, derive only the smallest necessary compatible detail inside established geometry. It remains chapter-local and never outranks approved WebPs.

## Approval Gate

Each environment pack should include enough references to make recurring wide, reverse, detail, and era-state views deterministic. If a required view/state cannot be reconstructed reliably from approved references, production is blocked until the pack is strengthened.
