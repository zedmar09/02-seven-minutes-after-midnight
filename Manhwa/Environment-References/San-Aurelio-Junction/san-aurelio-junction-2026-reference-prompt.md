# San Aurelio Junction 2026 Canonical Reference Prompt

Create a reusable canonical environment reference sheet for abandoned San Aurelio Junction in 2026.

## Absolute Style

STRICT FLAT 2D HUMAN-DRAWN KOREAN MANHWA/WEBTOON ENVIRONMENT REFERENCE. Clean linework, flat colors, restrained hard-edged cel shading, matte materials, neutral practical lighting. No photorealism, CGI/3D, glossy wet-floor reflections, cinematic grading, bloom, lens flare, painterly rendering, or depth-of-field.

## Structural Identity

Show a historically grand 1930s railway station now abandoned/redevelopment-bound:
- arched windows
- green-and-cream tile relationships
- iron structural members
- brass sign remnants
- boarded ticket windows
- plywood / redevelopment barriers
- cracked glass and damaged plaster
- rain entering only through physically plausible roof/window damage
- Cafe Siete located beside the old ticket hall
- station clock context that can support the story's fixed `12:07` clue

## Reference Views

Provide several geometry-first wide/medium views sufficient to understand Daniel's route from station interior to Cafe Siete, the cafe's relationship to ticket hall, and the station clock context.

No characters, no supernatural glow, no horror silhouettes, no cinematic abandoned-building glamour.
