# Environment References

Reusable environment canonicals belong to permanent locations, not chapters.

## Active Location Packs

- `San-Aurelio-Junction/`
- `Cafe-Siete/`

## Absolute Rule

When an approved environment WebP exists, it is geometry/layout authority. A generated strip may simplify background detail but may not redesign the location.

For this story, 1986 and 2026 views of the same location must share underlying structural geometry. Era-specific condition changes do not authorize independent layouts.

## Required WebP Rule

Reference prompts may generate local PNG first. After visual approval, manually convert to WebP and commit the exact `.webp`. Production strips must reference exact committed WebP paths.

Missing required environment WebP blocks rendered strip generation.
