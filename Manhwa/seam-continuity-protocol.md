# Seam Continuity Protocol

## Purpose

Technical strips are invisible production chunks of one reader chapter. Every approved strip must hand a deterministic end state to the next.

## Seam Is Not a Cut in Story Reality

A strip boundary cannot perform movement, repair, pickup, placement, time advancement, emotion reset, wardrobe reset or geometry reset.

If Strip N ends with an action completed, Strip N+1 starts from that completed result.
If Strip N ends on a deliberately in-progress action handoff, the exact grip/support/orientation/progress is written in both prompts.

## Inheritance — Absolute

Unless legal time/location cut or visible first action changes it, inherit:
- pose/support/facing/feet
- head orientation/eyeline when relevant
- hand occupancy/gesture/anatomical side
- worn items/gloves/hair/apron
- relative character distance/build
- emotional intensity
- held/placed objects
- object provenance/age/damage
- window/gate state
- exact Cafe clock minute
- station clock identity/location
- 1986/2026 state
- practical lighting/rain/steam/audio source
- evidence location

## Permanent Canon Wins

If previous render drifts permanent character identity, environment structure or recurring object design, repair toward approved canonical; do not propagate drift.

## Seam Classes

- **G geometry/state** — same physical scene state persists
- **A action handoff** — exact completed/in-progress mechanics specified
- **E emotion/dialogue** — intensity/eyeline/listening state carries
- **T time** — exact clock/time state carries; next change must be visible
- **END** — final chapter state only

## No Invisible Action Audit

At every seam ask:
- did any object change hand/location without visible movement?
- did a person change world position without step/route/legal cut?
- did a door/gate/window change open state without mechanism?
- did hand occupancy become convenient without placement?
- did clock advance because a new strip began?
- did fear/romance reset because camera changed?

Any yes = reject/repair.

## Active Seven-Minute Seam Ledger

Record at every active seam:
- Cafe clock time
- connection stable/flickering/closing
- Daniel location/hand props/glove state
- Tomas location/hand props/apron-pocket state
- service-window state
- crossing-object location/age/history
- Cafe 1986/2026 state
- flashlight/token/pastry/saucer/pencil states when relevant

## One-Object Provenance

After completed crossing, one authoritative location. Same-object close-up cannot become second real copy.

## Era Boundary

1986 furnishings/people/active fixtures cannot leak into 2026 except scripted co-registration. 2026 damage cannot overwrite 1986 structure.

## Clock Boundary

No silent minute advance. If N ends 12:04, N+1 starts 12:04 until visible/scripted 12:05.

Cafe/station clocks never swap roles.

## Contact Boundary

Prefer decisive grip/transfer/release inside one strip. If seam must occur:
- exact physical side
- grip pressure
- hand orientation
- object support
- depth relationship
must carry identically.

## Dialogue Boundary

Do not cut between a question and an answer if new strip would reset listener reaction/eyeline. When conversation crosses seam, seam-out describes who is listening, current expression, gaze target and whether humor/fear is active.

## SFX Boundary

Do not place SFX at next strip if physical action occurred in previous strip. Sound belongs to source moment.

## Final Stitch Audit

Inspect every 001→036 boundary at reading scale for:
- duplicate/missing movement
- dead double gap
- pose/position jump
- object teleport
- geometry jump
- wrong clock/time
- era contamination
- emotional/dialogue reset
- repeated/missing SFX
- visible production artifact.
