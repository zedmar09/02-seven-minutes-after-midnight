# Seam Continuity Protocol

## Purpose

Technical image boundaries must disappear after stitching. A reader must not be able to identify where `strip-###` ends.

## Canonical Anchor Rule

Before seam evaluation compare both strips against the relevant approved character/environment/object WebPs.

A seam is invalid even when Strip N visually matches Strip N+1 if both drift from permanent canon. Never preserve a mistake merely because it is consistent.

For Seven Minutes verify, where relevant:
- San Aurelio/Cafe Siete structural anchors
- counter/service-window geometry
- Daniel/Tomas identity and relative scale
- era state
- clock minute
- connection condition
- current object provenance/aging state
- current written-text carrier/state

## Approved Previous-Strip Rule — Absolute

For every strip after 001, use the immediately previous **CURRENTLY APPROVED** strip as temporary-state authority in addition to permanent canonicals.

Rejected, superseded, legacy-page, or pre-current-audit renders are not continuity authority.

## Seam Types

### G — Gutter Seam
Natural quiet transition. Compact and meaningful, never unused tail.

### A — Artwork-Continuation Seam
Bottom of Strip N and top of N+1 continue the same environment/composition/action.

### E — Effect/Atmosphere Seam
Rain, darkness, steam, light-collapse field, dust, or another physically established atmosphere continues.

## Start/End State Handoff — Absolute

Before N+1 compare approved END STATE of N to hardened START STATE of N+1.

Every unchanged state must match:
- character position/facing/feet/distance/support
- hands/held items/anatomical side
- emotional intensity/gesture
- wardrobe/sleeves/hair/accessories
- token/notebook/pencil/flashlight/tray/tongs/saucer/bread/paper
- service-window open/closed/unstable condition
- counter/door/glass state
- era state
- clock minute
- station/cafe lighting
- scratched/handwritten text state
- object age/damage/stain state

A strip boundary is not a time cut unless the script explicitly defines one.

## Object Provenance Seam Rule — Absolute

A story-critical object cannot materialize at N+1.

At every seam ask:
- where was the object at N end?
- who owned/held/supported it?
- what era/state was it in?
- is it in the same place/hand at N+1 start?
- if different, was there a visible action or legal cut?

Chapter 1 examples:
- one brass token is retrieved and dropped; it does not duplicate
- one tray is stabilized by Daniel/Tomas; later tray state must follow visible Tomas action
- one roll + one saucer cross forward and age as those same objects
- one acid-free sleeve crosses backward and goes into Tomas's apron pocket
- one flashlight falls on Daniel's side and does not silently return to his hand
- one notebook/pencil produces the Arturo note and later torn warning page
- one torn warning page returns as the same forty-year-aged page with Tomas's addition

## Era / Clock Seam Rule — Absolute

N+1 inherits the exact current time-slip state.

For Chapter 1:
- never jump 12:02 → 12:04 without the 12:03 events
- never return to 12:00 after time has advanced
- a 1986-open environment cannot silently become 2026 ruins before 12:07 closure
- 12:06 light-collapse state persists until the connection closes
- post-close 2026 state remains closed/abandoned unless new story action changes it

## Dual-Era Geometry Seam Rule — Absolute

When the same architecture continues across eras/seams:
- service window remains same structural opening
- counter footprint/depth remains coherent
- door/glass position remains stable
- fixed clock/menu-wall relation remains stable
- same camera axis may reverse but not mirror architecture

Do not let an A/E seam reveal that 1986 and 2026 were independently designed rooms.

## Physical Text Seam Rule

Text remains on the same carrier and preserves prior state:
- `TOMAS` scratch remains on 2026 glass
- second scratch appears only when story reveals it
- paper writing remains on same page/sleeve after crossing
- Tomas's addition appears only on returned aged page
- clock time remains on same clock face

Never split a speech balloon, note, critical scratch, clock face, or SFX word across a seam.

## Hand-Occupancy / Pose Seam Rule — Absolute

End hand/body support must be physically compatible with next start.

Reject if:
- held item vanishes without release/placement
- new item appears without pickup
- Daniel suddenly holds notebook/pencil/flashlight/paper in impossible combinations
- Tomas silently swaps tongs/tray/saucer/paper between hands when continuity matters
- wrist-catch hands change ownership/side across close-up
- body posture resets at seam

## Hair / Garment Seam Rule

Tomas's low tie, long hair mass, loose strands, apron, sleeve state and Daniel's jacket/glasses/gloves persist across continuous-scene seams. Flexible motion may change shape naturally but not redesign construction.

## No-Dead-Space Seam Rule — Absolute

Never create a seam by leaving a huge blank lower area. If a pause is needed, it must read through existing silence, rain, steam, darkness, architecture, clock pressure, or reaction. Do not invent filler text/SFX.

Reject double-gap joins.

## Overlap Strategy

When practical, repeat a small lower-edge continuity zone from N at the top of N+1 and crop the duplicate at stitch time. The overlap is representational continuation, not a second object/person or repeated dialogue.

## Seam QA Checklist

Before approving N→N+1:
- identical technical width
- permanent character canon correct
- permanent environment geometry correct
- exact era/clock state correct
- position/pose/facing/emotion handoff correct
- hand occupancy compatible
- object provenance continuous
- object age/damage/writing state continuous
- service-window state correct
- no duplicated/missing text
- no missing counter/wall/window segment
- no lighting jump without cause
- no body/object teleport
- no hair/wardrobe reset
- no technical label/header
- no excessive dead top/bottom gap
- no visible technical seam

If the join is obvious at phone-scroll speed or violates any story-state/canon rule, reject/regenerate the newer strip.
