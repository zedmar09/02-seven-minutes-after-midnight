# Seam Continuity Protocol

## Purpose

Technical strips are invisible production chunks of one continuous reader chapter. Every approved strip must hand a deterministic end state to the next strip.

## Strip Boundary Inheritance — Absolute

Unless the next strip begins with a legal time/location cut or an explicitly visible first action, inherit the previous approved strip's final:
- character pose/support/facing
- head orientation when relevant
- hand occupancy and gestures
- worn items and clothing-layer state
- relative character distance/height/build
- emotional intensity
- held/placed object state
- object provenance and age state
- service-window open/closed state
- exact clock minute
- 1986/2026 environment activation state
- practical light/rain state
- evidence locations

## Permanent Canon Still Wins

If a previous approved-looking strip contains permanent drift in character identity, structural environment geometry, recurring-object construction, or era architecture, correct the drift to approved canonical authority rather than propagating it.

## Seven-Minute Seam Ledger

During the active interval each seam records:
- current clock time
- whether connection is stable/flickering/closing
- Daniel location and current hand props
- Tomas location and current hand props
- service-window state
- which objects have crossed, their direction, and current age state
- exact notes/pages and who possesses them
- current cafe state on both eras

## One-Object Provenance

An object cannot exist on both sides after a completed crossing unless the composition is clearly a representational same-object detail. At seam out, state one authoritative location.

## Era Boundary

Do not allow 1986-only furnishings, passengers, intact finishes, or Tomas-side practical activity to leak into 2026 except through the scripted shared connection. Do not allow 2026 redevelopment damage, archive equipment, or broken-room condition to overwrite 1986.

## Clock Boundary

Do not silently advance or rewind time at a strip seam. If Strip N ends at 12:04, Strip N+1 starts at 12:04 until a visible/scripted progression establishes 12:05.

## Contact Boundary

If a seam occurs during hand/object threshold contact, preserve exact hand ownership, object orientation, depth, and physical relationship. Prefer not to cut a decisive contact mechanism exactly at the technical seam unless stitched art remains fully readable.

## Seam Audit

Before approving Strip N+1 compare its first read slice against Strip N's last approved read slice. Reject silent resets, duplicates, pose flips, hair/wardrobe changes, clock jumps, object-age resets, architecture flips, or emotional resets.

## Final Stitch Audit

After stitching, inspect every technical boundary at reading scale. There must be no visible duplicate beat, dead double-gap, character jump, object teleport, architecture jump, contradictory clock, era contamination, or production artifact.
