# Manhwa Vertical-Scroll Workspace

`Manhwa/` is the sole active visual-production pipeline for `Seven Minutes After Midnight`.

The former `Comics/` page/manga pipeline is decommissioned and must not be recreated. New chapters, revisions, reusable environment references, recurring-object references, production strips, rendered strips, and stitched chapters belong under this workspace.

## Authority — Absolute

For active production:
1. current user instruction
2. current chapter continuous-scroll plan + strip manifest
3. current strip exact script/state
4. approved character canonical WebPs
5. approved environment canonical WebPs
6. approved recurring-object canonical WebPs
7. binding global workflow/layout/seam/lettering/readiness/hardening rules
8. immediately previous APPROVED strip for temporary state/seam only
9. minimal canon-compatible derived micro-detail only

No old page prompt, old render, rejected render, or Markdown reference prompt overrides an approved visual canonical.

## Seven Minutes Project-Specific Continuity

Every active strip must preserve, when relevant:
- exact story-world era: 1986 / 2026 / active shared threshold
- exact cafe-clock minute and connection condition
- shared architecture across both eras
- service-window open/closed/unstable state
- object origin era and provenance
- forward/backward aging/adaptation state
- Daniel/Tomas body position and threshold side
- scratched-glass text state
- station/cafe lighting and occupancy state
- offscreen 1986 audio source geography

A camera cut or technical-strip boundary is never permission to change any of these.

## New Chapter Rule

Before visual production of every new chapter:
- inventory characters and confirm approved cards
- inventory environments; reuse approved location packs where possible
- create/approve canonicals for genuinely new recurring locations
- identify recurring plot-critical objects and create/reuse object canonicals
- lock timeline/era/clock states
- build one continuous-scroll beat plan
- build a deterministic strip manifest
- run real-scenario continuity audit
- run clean-room preproduction audit

## No Dead Space — Absolute

Large vertical space must perform a story function: existing narration/time transition, meaningful silence, suspense/reveal delay, reaction hold, atmosphere, rain/steam continuation, environmental geography, or controlled seam.

Never invent filler narration, dialogue, SFX, ghost silhouettes, decorative particles, or empty canvas merely to occupy height.
