# Chapter 1 Production-Strip Global Contract

This file is binding for every `Production-Strips/strip-###-...md` prompt. A local strip prompt may be stricter but never weaker.

## Output Identity

Create exactly ONE tall full-color flat-2D Korean manhwa/webtoon technical strip for the specified Chapter 1 beat range.

Technical labels are never reader-visible. Never render strip numbers, V-beat IDs, panel/scene/shot names, filenames, reference labels, state-variable names, QA notes, crop guides, or production metadata.

## Absolute Visual Style

STRICT FLAT 2D HUMAN-DRAWN KOREAN MANHWA/WEBTOON.

Required:
- clean intentional linework
- flat matte local colors
- restrained hard-edged cel shading only
- stable adult anatomy/proportions
- natural hands
- ordinary human-eye perspective
- mobile-readable staging
- matte skin/hair/fabric/metal/glass/tile/paper/food/rain/architecture

Reject:
- photorealism or semi-photorealism
- 3D/CGI/game-render appearance
- painterly/airbrushed rendering
- glossy/plastic/wet character finish
- beauty-ad shine
- mirror-like gratuitous reflections
- cinematic grading
- bloom, lens flare, volumetric light, exaggerated rim light
- depth-of-field blur
- fisheye/ultra-wide distortion
- AI-polished over-rendering

## Required Authority Behavior

Before rendering a strip:
1. attach every required approved character WebP listed locally
2. attach every required approved environment WebP listed locally
3. attach every required approved recurring-object WebP listed locally
4. for Strip 002+, attach the immediately previous APPROVED rendered strip unless the local prompt explicitly requires an additional earlier rendered state

Missing required authority = STOP. A Markdown prompt is not a visual-canonical substitute.

Permanent WebP authority controls stable identity/geometry/object design. Previous approved strip controls only temporary state: pose, facing, hand occupancy, held/placed props, clock minute, damage/age state, lighting, emotional intensity, and seam position.

## One Continuous Reader — No Invisible Action Rule

The reader must not be asked to infer continuity-critical movement that never appears.

For each meaningful change, use:
`START STATE → CAUSE → VISIBLE MOVEMENT → CONTACT/SOURCE → RESULT → REACTION/SEAM STATE`.

Do not hide any of the following off-panel merely to save space:
- gate/door/window opening mechanics
- picking up/putting down a critical prop
- tray catch/support/release
- counter brace and wrist catch/release
- service-window opening
- tongs→bread→saucer preparation
- threshold object crossing
- paper writing/tearing/folding/pocketing
- flashlight roll/fall/retrieval
- pencil break state
- warning-page return transit
- final flashlight-angle change revealing scratch

A camera change is not an action.

## Adjacent Slice = New View, Not Reset

Across adjacent read slices preserve every unmodified state:
- world-space character positions
- feet/support/torso/shoulder/head facing
- anatomical hand side and occupancy
- glasses, gloves, apron, hair cord and worn accessories
- object count/location/orientation/age/support
- counter/window/gate/door geometry
- Cafe clock minute
- station clock identity/location
- 1986/2026 state separation
- lighting source direction
- rain/steam/audio source
- emotional intensity

Occlusion is not disappearance.

## Environment / Dual-Era Geometry

Cafe Siete is ONE permanent architecture with two historical states.

Never move the following for composition:
- counter body/location
- service-window wall/opening/track
- cafe clock location
- menu-wall relationship
- entrance/gate
- painted glass/sign zone
- pastry-service zone
- fixed circulation route

1986 vs 2026 differences may affect condition, removable furniture, occupancy, lighting, surface wear, damage, clutter, but not structural footprint.

No glowing portal seam, time vortex, neon edge, holographic split screen, or fantasy energy ring. Era disagreement reads through real historical state.

## Two-Clock Rule

`CLOCK-CAFE-01` = brass-rimmed Cafe Siete connection clock.
- inactive baseline 12:07
- resets to 12:00 in Strip 009
- active progression 12:01→12:07
- closure authority

`CLOCK-STATION-01` = large ticket-hall historical station clock.
- separate object/location
- baseline/final 2026 clue fixed 12:07
- never resets/counts the seven-minute interval

Never merge, substitute, or show contradictory decorative clock times.

## Service Window / Counter Physics

Shared counter = unstable co-registered overlap surface. Brief incidental contact may occur; sustained unstable overlap can produce phase-shear pain.

Service window = stable narrow aperture for small objects and limited hand contact. Stable aperture does not permit full-body crossing.

Do not invent new threshold behavior per strip.

## Object Provenance

Same-object close-up is representational, not a duplicate.

Track at minimum:
- `TOKEN-01`
- shared bread tray
- crossing roll + saucer
- `PAPER-REAL-01`
- warning page
- `PENCIL-DANIEL-01`
- Daniel flashlight
- Tomas tongs

For any transfer: show source support → motion → threshold/contact → destination support → source release.

## Hand Occupancy / Body Support

Exactly two hands per person. Every held object must have real support. If both hands are needed, first place/release other objects visibly.

Never use an extreme crop to hide impossible support.

## Dialogue Flow

Dialogue is adult, concise, and connected.

Reader-friendly order:
1. visible cause/context
2. speaker line
3. listener reaction
4. answer/follow-up
5. optional humor only after comprehension is secure

Do not stack several back-and-forth exchanges into one tiny balloon cluster. Use vertical space.

After 12:05, reduce joke density. Humor may release tension but cannot erase urgency.

## SFX Ownership

Every SFX has one real source and exact timing. Place it near the action source without covering contact/evidence.

Do not use random atmospheric SFX to fill empty space. Rain/station ambience may recur only when physically present.

Important Chapter 1 source families:
- paper/ruler: `FLIP`, `SHFF`, `TAP`, `TIK`
- door/steps/rain: `KLAK`, `THUNK`, `TAP...`, `TIK...`, `PLIK`
- gate: `KRRK`, `SKRRRNNK`
- token/clock/lights: `TINK`, `KLIK`, `TK`, `TICK`, `FZZT`
- tray/tongs/saucer: `CLINK`, `THK`, `SHHK`
- phase contact/window: `TZK`, `KZT!`, `SKRRRRK`
- paper/pencil: `FSSSH`, `SCRITCH...`, `RRIP`, `TK`
- flashlight: `RRR...`, `CLACK`

## Camera Axis / Eyelines

Daniel/Tomas uninterrupted conversation preserves world-space sides around counter/service window. Reverse shots may flip screen-left/right but not exchange physical positions.

Eye targets must be real: speaker, Cafe clock, service window, station source, scratched glass, falling object.

If crossing the 180° axis is useful, first establish a neutral reorientation view.

## Mobile Evidence Legibility

Critical proof cannot be microscopic:
- 12:00–12:07 Cafe-clock states
- station-clock 12:07 clue
- `TOMAS`
- token `7`
- one-tray shared catch
- counter hand depth failure
- wrist grip/release
- service-window track/open state
- roll/saucer aging
- exact paper text
- apron pocket storage
- pencil chip state
- glove-to-bare fingertip warm contact
- returned aged page
- `FIRE STARTS IN THE SERVICE CORRIDOR.`

Use adjacent SAME-OBJECT detail if necessary; never resize the object in world space.

## Vertical Rhythm

A strip is not five equal boxes. Allocate height by reader function:
- small setup/action initiation
- larger mechanism proof where needed
- reaction/dialogue breathing room
- deliberate suspense hold where scripted

Use compact dark gutters between read slices. Larger gaps only for real suspense/silence/time transition. No giant dead bottom.

## Seam Rule

End each strip on an exact state that the next prompt can inherit. Do not end with ambiguous verbs such as “begins to move” unless the next strip explicitly starts from that exact in-progress action.

Never split decisive contact at a technical seam if doing so makes ownership/result unclear.

## Rejection Gate

Reject the render if:
- a critical action jumps between states
- dialogue order is confusing
- SFX has no source
- character identity/anatomy drifts
- hand occupancy is impossible
- object duplicates/disappears/teleports
- Cafe geometry changes
- clock identity/time is wrong
- era states contaminate each other
- text is unreadable
- final composition becomes glossy/cinematic/3D
- reader-visible production metadata appears

Do not approve the next strip until the current rendered pixels pass.
