# Chapter 1 Production Strips

This directory contains the 18 technical generation prompts for one continuous reader-visible Chapter 1.

## Absolute Rule

Technical strips are production chunks only. Never render strip numbers, beat IDs, state labels, attachment filenames, QA text, or technical headings inside artwork.

## Sequential Rule

Generate strictly in order:

`001 → 002 → ... → 018`

Strip 002 onward may use only the immediately previous **CURRENTLY APPROVED** rendered strip for temporary pose/object/era/seam continuity.

A rejected/superseded render is not authority.

## Permanent Authority

Every strip also attaches the exact required approved character/environment/object WebPs. Previous strip never overrides permanent canon.

## Current Status

All strip prompts are preproduction specifications. Rendered generation is blocked until the exact required approved WebPs exist.

## Stitch Rule

After all 18 current renders pass visual QA, stitch at identical width, remove any intentional overlap duplicates, and run a fresh clean-room audit of the entire chapter. Only then may Chapter 1 become `PRODUCTION COMPLETE`.
