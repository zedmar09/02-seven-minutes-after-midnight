# Vertical Scroll Layout Guide

## One Chapter, One Scroll

Finished Chapter 1 is one centered continuous vertical reader. The 36 technical strips are invisible production chunks.

## Width Lock

Use one fixed generation width. Do not independently resize strips before stitching. Stitch first; resize completed master uniformly if needed.

## Canonical Environment Anchor — Absolute

Every camera/view must be physically possible inside approved San Aurelio/Cafe geometry. Preserve footprint, counter, service window, Cafe clock/menu-wall, gate/track, glass/sign zone, station route, fixed scale and reverse-angle truth.

1986/2026 are historical states of same architecture.

## No Invisible Action — Absolute

If a state matters later, show the movement that changes it.

Examples:
- walking to a new position requires a readable step/route or legal time/location cut
- held object becomes placed only after surface support/release
- gate/window opens through real contact/track motion
- tray tilts before catch; catch before stabilization; stabilization before set-down
- wrist grip closes before pain; release/air gap before later window action
- page tears/writes/crosses before it can be held on other side
- flashlight is nudged before roll, rolls before fall, falls before floor state, retrieved before hand-held final use

A camera cut cannot perform an action.

## Adjacent Slice = View Change, Not Reset

Preserve:
- feet/support/body/facing
- anatomical hand side and occupancy
- glasses/gloves/apron/hair cord
- object count/location/orientation/age/support
- token/flashlight/pastry/saucer/page/pencil states
- service-window/gate state
- Cafe clock minute
- dual-era state
- lighting direction
- audio-source direction
- emotion

Occlusion is not disappearance.

## Strip Seam Rule

A technical seam must land on one of:
- completed stable geometry/state
- explicitly defined action-handoff state
- exact clock-state handoff
- intentional emotional handoff

Do not end a strip with vague `he starts to...` unless next strip explicitly starts from exact in-progress mechanics.

Critical contact/transfer should stay inside one strip when splitting would make ownership ambiguous.

## Camera Axis / Eyelines

Uninterrupted Daniel/Tomas dialogue preserves world-space sides around counter/window. Reverse view may flip screen sides, not physical story positions.

Eyes look at actual source: speaker, clock, window, PA direction, scratch, falling flashlight.

Cross 180° axis only after neutral reorientation if required.

## Perspective

Ordinary human-eye/manhwa perspective. No fisheye/ultra-wide distortion, fake contact through lens compression, or scale-changing foreground tricks.

## Mobile Evidence Legibility

Cannot be microscopic:
- station 12:07
- Cafe clock minute
- token `7`
- `TOMAS`
- tray co-support
- counter depth failure
- wrist grip/release
- service-window open state
- saucer crossing/aging
- `I AM REAL.` sheet
- apron pocket storage
- pencil chipped point when continuity-relevant
- warning writing
- glove-to-bare touch
- returned aged page/reply
- final fire warning

Use adjacent SAME-OBJECT detail if wide is insufficient. Do not resize object in story world.

## Cause / Action / Reaction Vertical Order

Top-to-bottom must remain causal:
- cause before movement
- movement before contact
- contact before result
- result before reaction/dialogue that refers to it
- question before answer
- answer before joke that comments on it
- clock time before dialogue relying on remaining minutes

If a composition cannot preserve order, use more vertical space/slices.

## Dialogue Breathing Room

Do not use a dense script-like balloon stack. Give listener reaction enough space when it changes next line meaning.

Adult chemistry should read from eye contact, proximity, restrained pauses, object handling, and interruption—not decorative sparkle or compressed text walls.

## Sound-Source Direction

SFX and offscreen voices must point to real sources. When source is initially unseen, show character orientation before later reveal if needed.

## Crop / Gutter / Divider Safety

Do not put decisive hand/prop/clock/text/contact exactly on crop or seam. Give compact breathing room.

Small black gutters between read slices. Larger gap only for real suspense, silence or legal time transition. No giant filler.

## Depth / Contact

Flat overlap does not prove grip/contact. Fingers wrap/meet, saucer is supported, page has source/destination, feet share correct floor plane, gate/window follows track.

## Hand Occupancy / Support

Exactly two hands per person. If both needed, place/release other props first. Close-up cannot hide impossible support.

## Flexible Material / Gravity

Paper, hair, apron, rain, falling flashlight, bread and cloth obey gravity/support. No floating objects/clipping.

## Dual-Era Separation

Era difference uses historical condition/occupancy/fixtures/light, not portal VFX/color filter. Structural correspondence must remain understandable.

## Physical Text Plane

Evidence text stays on real carrier and follows perspective/boundaries. Same-object detail allowed for readability.

## No Dead Canvas

Whitespace/black space must perform silence/suspense/transition/reveal. Never pad because strip target height is unused.

## No Traditional Page Artifacts

No page numbers, equal page-grid template, strip/beat labels, QA notes or technical metadata.
