# Character References

This directory contains reusable canonical character-card prompts and, after visual approval, the committed WebP authorities for recurring characters in `Seven Minutes After Midnight`.

## Authority Rule

Once a character card is generated, visually approved, manually converted to WebP, and committed, that exact `.webp` is permanent visual identity authority across every later chapter until deliberately superseded.

Do not create chapter-specific redesigns for the same recurring character.

## Required Format

Each recurring character should have:

```text
<character>-canonical-flat2d-chatgpt-image-prompt.md
<character>-canonical-flat2d.webp
```

The Markdown prompt is a specification. It is **not** a substitute for the approved WebP.

## Missing-Asset Rule

If a visible strip requires a recurring character whose approved canonical WebP does not yet exist, generation is blocked. Never improvise from prose, an old page render, a rejected image, or another story's character reference.

## Visual Style

All cards obey `character-card-standard.md` and `../Manhwa/style-guide.md`:

**STRICT FLAT 2D HUMAN-DRAWN FULL-COLOR KOREAN MANHWA/WEBTOON.**

No photorealism, 3D/CGI, glossy skin/hair, painterly rendering, cinematic grading, bloom, lens flare, depth-of-field blur, or AI-polished over-rendering.
