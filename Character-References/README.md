# Character References

This directory stores reusable canonical character prompts and approved repository WebP authorities for `Seven Minutes After Midnight`.

## Authority

Approved `.webp` character cards are permanent visual identity authority. Markdown prompt files define how to generate/rebuild those cards but do not substitute for an approved WebP.

## Fictional-Identity Rule — Absolute

Story geography is fictional under `Manhwa/Continuity/fictional-setting-bible.md`.

Do not assign characters real-world nationalities, nationality combinations, country flags, national uniforms/badges, or location-specific identity markers merely from their names or appearance.

Describe visible identity directly through age, face geometry, skin tone, hair, build, permanent marks, wardrobe and recurring accessories. Character surnames do not imply a real country.

`Korean manhwa/webtoon` remains a production-style term only.

## Required Before Strip Generation

Chapter 1 requires:
- `daniel-soriano-canonical-flat2d.webp`
- `tomas-rivera-canonical-flat2d.webp`

If another recurring character becomes visually present, create and approve that character's canonical before the appearance.

## File Pattern

- `<character>-canonical-flat2d-chatgpt-image-prompt.md`
- `<character>-canonical-flat2d.webp`

## Visual Rule

Every canonical must pass strict flat 2D human-drawn Korean manhwa/webtoon QA: clean intentional linework, flat colors, restrained hard-edged cel shading, matte materials, stable adult anatomy/proportions, and no photoreal/3D/glossy/cinematic/painterly drift.
