# Character References

This directory stores reusable canonical character prompts and approved repository WebP authorities for `Seven Minutes After Midnight`.

## Authority

Approved `.webp` character cards are permanent visual identity authority for Manhwa generation. Markdown prompt files define how to generate/rebuild those cards but do not substitute for an approved WebP.

## Required Before Strip Generation

Chapter 1 requires:
- `daniel-soriano-canonical-flat2d.webp`
- `tomas-rivera-canonical-flat2d.webp`

If Lilia Ramos becomes visually present rather than voice-only, her approved canonical WebP becomes required before generating that appearance.

## File Pattern

- `<character>-canonical-flat2d-chatgpt-image-prompt.md`
- `<character>-canonical-flat2d.webp`

## Visual Rule

Every canonical must pass strict flat 2D human-drawn Korean manhwa/webtoon QA: clean intentional linework, flat colors, restrained hard-edged cel shading, matte materials, stable adult anatomy/proportions, and no photoreal/3D/glossy/cinematic/painterly drift.
