# SFX Lettering Guide

Working reference assembled from this story's existing material. This reorganization does not adopt canon, approve the manuscript, or release production.

No SFX script is released. Every future SFX record requires:

- sound source
- reader-facing meaning
- intensity
- language
- translation context
- lettering intent

SFX text belongs to the separate lettering stage, not panel artwork.
