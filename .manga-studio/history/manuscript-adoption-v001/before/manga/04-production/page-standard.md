# Page Standard

Working reference assembled from this story's existing material. This reorganization does not adopt canon, approve the manuscript, or release production.

English, left-to-right, paged monochrome; quality profile: high. The configured 1654 x 2339 dimensions are runtime placeholders, not an approved print standard.

Retain the requested panel-first workflow. A panel is not a finished page. Approve panel artwork before composition and separate lettering. No page or panel jobs are released.

Panel artwork prohibits:

- dialogue
- captions
- balloons
- SFX text
- borders
- page numbers
- signatures
- watermarks
- color

Story, storyboard, references and production approvals are still required. Codex must never generate, edit, retouch or correct artwork.
