# Reference Library

No approved visual references are available. `manga/02-references/reference-register-v001.json` therefore contains an empty asset list and no invented image paths.

The `characters`, `environments`, `objects` and `effects` folders are organizational placeholders only. A category does not create a reference, promise an effect design or grant approval.

When the story and required gates permit it, reference requests must be structured ChatGPT Image Generation Jobs. Dependent jobs may use only actual, approved, hash-locked references with exact attachment lists. Codex must not generate, edit or correct the artwork.
