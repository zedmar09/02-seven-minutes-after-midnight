# Manga Workspace

This is the visible organization for Seven Minutes After Midnight. The project root remains the enclosing repository; managed authorities stay under `.manga-studio/`.

| Directory | Role |
|---|---|
| `manga/00-series/` | Series-direction and evidence indexes |
| `manga/01-style/` | Accepted format direction and required production constraints |
| `manga/02-references/` | Empty reference categories and an availability register |
| `manga/03-story/` | Versioned chapter reading copies with canonical hash bindings |
| `manga/04-production/` | Reserved chapter production organization and readiness status |

The root `MANGA-STUDIO.md` is the clickable starting point. All stored artifact paths in indexes are relative to the project root. Do not treat this folder as original source input, and do not edit a reading copy independently of its managed manuscript version.

Nothing in this folder activates canon, a manuscript, a storyboard or a production gate. Empty folders are not assets and do not imply approval.
